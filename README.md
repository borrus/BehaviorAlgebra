Behavior Algebra — Порт и верификация поведения
================================================

Учебный проект по дисциплине «Организация ЭВМ / Алгебра динамических отношений» (СПбГУ).
Демонстрирует применение алгебры динамических отношений и алгебры поведения
к задаче планирования доставки контейнеров в порту.


ЧТО ДЕЛАЕТ
----------

Программа моделирует порт с автокарами, контейнерами и складами и позволяет:

1. Строить план доставки — каким автокаром какой контейнер поедет на какой склад.
2. Моделировать сбои — поломка автокара, потеря связи.
3. Автоматически перепланировать после восстановления ресурсов.
4. Показывать отношения порта в виде таблиц.
5. Верифицировать поведение — формальный анализ свойств.


АЛГЕБРА ДИНАМИЧЕСКИХ ОТНОШЕНИЙ
-------------------------------

Основная идея: описать порт как множество кортежей и применять к ним три операции.

  ∪  Объединение — все свободные ресурсы: автокары + контейнеры
  ∩  Пересечение — пары (автокар, контейнер), подходящие по весу
  ∘  Композиция  — склейка цепочки: Автокар → Контейнер → Склад

Ключевые отношения:

  Capacity    ⊆ Cart × Container        — какой автокар может везти какой контейнер
  Destination ⊆ Container × Warehouse   — куда едет контейнер
  Composed    = Capacity ∘ Destination  — кто может доставить куда

План доставки: Active ∩ Capacity, затем ∘ Destination → список маршрутов.


АЛГЕБРА ПОВЕДЕНИЯ (БОНУС)
-------------------------

Дополнительно реализована формальная верификация поведения:

  - Поведение описывается формулой a.u (префиксинг) и u + v (выбор).
  - Из формулы строится LTS (Labeled Transition System).
  - Работает model checking: проверка достижимости Δ, 0, живости.


ТЕХНОЛОГИИ
----------

  - C# 12 / .NET 8
  - WPF — графический интерфейс
  - LINQ — операции над отношениями
  - Собственная реализация алгебры, без сторонних библиотек


СТРУКТУРА
---------

  BehaviorAlgebra.sln
    BehaviorAlgebra.Core     — ядро (модель, алгебра, симуляция, LTS)
      Model/                 — Cart, Container, Warehouse, Route, Port
      Algebra/               — Relation<,>, RelationsAlgebra (∪, ∩, ∘)
      Simulation/            — PortSimulator (шаги времени, сбои)
    BehaviorAlgebra.App      — WPF-приложение (GUI)
    BehaviorAlgebra.Console  — консольный тест LTS


КАК ЗАПУСТИТЬ
-------------

  1. Открыть BehaviorAlgebra.sln в Visual Studio 2022.
  2. Назначить BehaviorAlgebra.App стартовым проектом.
  3. F5.


СЦЕНАРИЙ ДЕМОНСТРАЦИИ
---------------------

  1. Вкладка «Порт» → «Построить план» — 4 маршрута.
  2. «Шаг времени» ×2 — контейнеры доставлены.
  3. «Сломать автокар» — сбой, маршрут отменён.
  4. «Шаг времени» ×5 — ремонт + автоматическое перепланирование.
  5. «Потеря связи» — сбой связи.
  6. «Шаг времени» ×3 — связь восстановлена автоматически.
  7. Вкладка «Отношения» — таблицы отношений.
  8. Вкладка «LTS» → «Верифицировать» — формальный анализ.
